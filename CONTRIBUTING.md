# Contributing to Ryv AI

Thank you for your interest in contributing!

The full contribution guide is in the docs: **[packages/docs/development/contributing.md](packages/docs/development/contributing.md)**

It covers dev setup, adding LLM providers, VCS adapters, language parsers, skills, dashboard changes, commit conventions, and the PR checklist.

---

## Quick Start

```bash
git clone https://github.com/ivoyant-eng/AgnusAi.git
cd AgnusAi
pnpm install
pnpm build
```

**Prerequisites:** Node.js 18+, pnpm 8+, Docker (for Postgres + Ollama).
